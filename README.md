# 🌸 Portfolio Web — Ana Rosa Fuentes Pérez

## 🎯 ¿Por qué he creado esta web?
He diseñado y desarrollado este portfolio con el objetivo de **centralizar y presentar mi perfil profesional de forma viva, transparente y 100% personalizada**. 

En lugar de usar plantillas genéricas, esta plataforma me permite:
- **Demostrar mis habilidades reales:** Aplicando diseño adaptativo (*responsive*), maquetación moderna con *glassmorphism* y animaciones interactivas en código limpio.
- **Mostrar mis proyectos en producción:** Dar visibilidad a desarrollos reales que he realizado para clientes (BCM Asesor, Imporex, Gestregistro).
- **Reflejar mi identidad:** Unir mi faceta técnica en **DAM** y **Salesforce** con mi perfil creativo en un espacio digital que me representa.

## 🛠️ Tecnologías Utilizadas
- **Estructura y Estilos:** HTML5, CSS3 (Variables, Flexbox, Grid, Animaciones).
- **Control de Versiones y Despliegue:** Git, GitHub.
- **Especialización técnica general:** Salesforce Cloud, WordPress, Elementor, Java, SQL, Firebase, REST APIs.
